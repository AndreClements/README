## Design Principles

1. **Self-sufficient reading.** Each essay is written so a reader who follows *no* links still receives a coherent introduction to the repository's project. Links enrich; they do not gate.
2. **Type-native voice.** Each essay is written in the literary register, pacing, and concern-set that research suggests resonates with that Enneagram type. This is the parametric principle applied to reading: *same content, different entry point*.
3. **Honest external research.** The essays draw on scholarship beyond this repository to avoid echo-chamber effects. Sources are collected here.
4. **Links describe destinations.** Where a link appears, the surrounding prose tells the reader what they would find if they followed it — enough to decide whether to click.

## External Research Notes

### On Communication Style and Enneagram Type

The differentiation of literary register per guide draws on converging findings:

- **Wagner's "Nine Lenses" model** treats each type as a distinct cognitive-perceptual schema that filters incoming information differently. This directly supports the premise that the *same* content benefits from *different* presentation.
- **Palmer's Narrative Tradition** demonstrates that types learn best from hearing experience described *in their own attentional style* — not from external description but from first-person phenomenology.
- **Lapid-Bogda's coaching framework** provides type-specific communication guidance: what to lead with, what to avoid, how to pace feedback.
- **Chestnut's shadow work** identifies the defense mechanism each type will deploy against a framework's claims — reaction formation (1), repression (2), identification (3), introjection (4), isolation (5), projection (6), rationalization (7), denial (8), narcotization (9). The guides are written to work *with* rather than against these defenses.
- **Daniels' clinical panels** at Stanford demonstrated that types consistently self-report distinct attentional patterns, emotional default states, and preferred information-processing modes.

### On Psychometric Validity

The Enneagram's empirical status is mixed (see [ENNEAGRAM.md §10](../../docs/lib/ENNEAGRAM.md) for the full honest assessment). The guides use the Enneagram as a *heuristic for communication design*, not as a clinical instrument. The parametric principle — *same medicine, different patient* — does not require psychometric perfection; it requires that meaningful individual differences exist in how people process information. This is well-established across personality psychology, independent of any specific typology.

### On the Barnum Effect

Any type-targeted writing risks the Forer/Barnum effect: readers accepting generic statements as personally meaningful. The mitigation strategy in these guides is *specificity over flattery*. Each essay names the type's likely resistance, not just its strengths. Each essay includes external challenges to the repository's claims. The goal is recognition, not seduction.
