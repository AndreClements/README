# README — Quickstart (for first-time readers)

## What is this?

This repository is a **living, version-controlled cyber artist's book** — the personal operating system of André S Clements. It is written in the idiom of a software manual, but it documents a *praxis*: a reflexive system for making art, navigating relationships, and operating ethically under constraint. It is not software. It is not self-help. It is a generator that yields artifacts, connections, and (sometimes) joy.

---

## The Core Moves

- **as-if** — Operate provisionally. Treat the system as usable without believing its essence. Engage, but hold it lightly.
- **if-not** — Run a parallel audit thread. Look for mismatch, harm, hidden intent. The counter-voice stays on.
- **scale care by risk_index** — `risk_index = complexity × power × distance_from_wetware`. The higher the risk, the deeper and more frequent the checks.

**One ethic:** sovereignty over victory. Maintain integrity and agency; do not optimise for winning.

**One check:** BODY. Phenomenological verification — if it doesn't register in the body or in material contact, it's gloss. Write down what held and what failed.

## The Session Ritual (7 steps)

Any focused work session — writing, making, designing, debugging a relationship — can follow this pattern:

1. **Soft-Contract** — Establish scope, constraints, and duration. Name what you're here to do.
2. **Plan** — Outline the moves. Keep it light; the plan will bend.
3. **Pass A (As-If)** — Execute provisionally. Assume the system works; build forward.
4. **Pass B (If-Not)** — Parallel audit. Track mismatch, harm vectors, what was missed in Pass A.
5. **paintWithScalpel** — Make precise, consent-aware incisions. Cut where needed; no more, no less.
6. **Clean Brushes** — Restore integrity. Document state. Close what was opened.
7. **Validation Note** — Record in the BODY: what held, what failed, what surprised.
