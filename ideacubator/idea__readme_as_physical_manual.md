The repo is already a manual. \
A physical edition doesn't translate it — \
it completes the metaphor.

Git history is the ring-binder mechanism. \
Each commit is a page swap. \
Each tag is a printing.

The book is never definitive. \
That's the whole point. \
The current state is just the current state — \
like those IBM binders with their replacement pages, \
the physical object was always designed for change.

---

Snapshot editions: \
freeze a git state, print it, bind it. \
1/1 or very small runs. \
Art objects, not mass market. \
Each one a forensic record of a moment in the system's becoming.

The "maculate design" philosophy maps perfectly to print — \
patina, imperfection, corrupted boot logs, \
acknowledged scars rendered as typeset material. \
An artist's book dressed as a tech manual. \
The tension is the work.

---

The 9 enneagram guides are 9 entry points to the same book. \
9 possible dust jackets. \
9 reading orders. \
Parametric authorship made physical: \
same content, different door.

---

Nostalgia for the thick spiral-bound manual era \
meets CI-accelerated authorship. \
Coding is dead, long live coding. \
The manual is dead, long live the manual.
